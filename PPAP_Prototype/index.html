개인정보 처리방침 3개국 진단 프로토타입

회사의 국문 개인정보 처리방침과 실제 처리 현황을 바탕으로 대한민국, EU, 캘리포니아 기준에서 빠진 항목과 보완 포인트를 빠르게 점검하는 웹 프로토타입입니다.

한국 / EU / 캘리포니아 체크리스트 중심 가벼운 문장 힌트 스캔 포함
이번 버전의 방향

문장별 법조문 판정까지 가기보다, 먼저 입력 기반 체크리스트와 정책 문구의 빠른 힌트 스캔으로 실행 가능한 MVP를 만듭니다.

입력

서비스 현황 입력

샘플 입력을 불러오면 진단 결과가 바로 보입니다.

1. 서비스 기본 정보

진출 예정 권역

2. 실제 처리 현황

3. 고지 / 동의 / 권리

현재 제공 중인 권리

4. 아동 / 쿠키 / 자동화된 결정

출력

진단 결과가 여기에 표시됩니다

입력을 채운 뒤 진단 실행을 누르세요. 이 프로토타입은 체크리스트 방식으로 우선 구현되어 있고, 정책 문구는 키워드 수준으로만 보조 점검합니다.
