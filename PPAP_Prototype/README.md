# 개인정보 처리방침 3개국 진단 프로토타입

체크리스트 중심의 정적 웹 프로토타입입니다.

## 실행 방법

1. `C:\Users\s2205\OneDrive\Desktop\PPAP_Prototype\index.html` 파일을 브라우저로 엽니다.
2. 또는 폴더에서 `index.html`을 더블클릭합니다.
3. `샘플 입력 불러오기`를 누르면 바로 예시 진단 결과를 볼 수 있습니다.

## 이 버전에서 되는 것

- 회사 / 서비스의 처리 현황 입력
- 한국 / EU / 캘리포니아 기준의 1차 진단
- 처리방침 문구의 가벼운 키워드 힌트 스캔
- 권역별 점수와 보완 포인트 표시

## 이 버전에서 아직 안 하는 것

- "이 문장이 GDPR 몇 조를 위반한다" 수준의 정밀 판정
- 실제 법률 자문 대체
